Уведомления о заявках

Как получать уведомления, когда клиент оставляет заявку на сайте:

1. Email (Web3Forms) — рекомендуется

  1. Зайдите на web3forms.com
  2. Укажите email, на который приходят заявки
  3. Скопируйте Access Key и вставьте ниже
  4. Нажмите «Сохранить настройки»

2. Telegram

  1. Напишите боту @BotFather → /newbot → получите токен
  2. Напишите своему боту любое сообщение
  3. Откройте https://api.telegram.org/bot<ТОКЕН>/getUpdates — найдите chat.id
  4. Вставьте токен и Chat ID ниже

3. Общий список заявок (Google Таблицы)

  1. Создайте Google Таблицу с колонками: дата, имя, телефон, email, комментарий, статус
  2. Расширения → Apps Script → вставьте скрипт приёма заявок (doPost/doGet)
  3. Опубликуйте как веб-приложение → скопируйте URL сюда
  4. Тогда заявки будут видны и на сайте, и в таблице
