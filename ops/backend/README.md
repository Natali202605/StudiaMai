# Серверная часть (не веб-корень)

Исходники Node API для будущего запуска вне статической раздачи сайта.

На Timeweb в настройках деплоя укажите команду сборки `rm -rf ops`, чтобы каталог не копировался на публичный диск приложения (код остаётся в private GitHub).  
Дополнительно пути `/ops/*`, `/backend/*`, `/server/*` → 404 (см. Caddyfile).
