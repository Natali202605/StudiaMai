# Запуск и откат

Опубликованный сайт по-прежнему открывается с GitHub Pages. Этот репозиторий не переключает DNS и не входит в панель купленного хостинга.

## Когда домен укажет на свой сервер

1. Заполнить `.env` по образцу `.env.example`. Секрет и пароль администратора задаёт владелец. В Git их не класть.
2. `CORS_ORIGINS` — точный адрес сайта. Пока он неизвестен, посторонние сайты к API не допускаются.
3. Сервер не запускается, пока секрет короче 24 символов или пароль короче 10.
4. Первый администратор берётся из переменных окружения. Страница регистрации нового администратора закрыта.
5. Заявки с формы на GitHub Pages по-прежнему идут письмом на почту студии и в админку браузера. На свой API они пойдут только после того, как в настройках сайта будет указан адрес API.

## Откат

Вернуть предыдущую ветку `main` и заново выложить её. Файлы заявок на диске сервера при откате кода сами не удаляются. Их разбирает оператор.
