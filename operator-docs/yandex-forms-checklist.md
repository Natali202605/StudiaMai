# Чеклист Яндекс.Форм (оператор)

## Форма записи `https://forms.yandex.ru/u/6ad643dd852af364ddc7a26c`

- [ ] Приём ответов **открыт**
- [ ] В форме: согласие на обработку ПДн и ссылки на https://studia-mai.ru/privacy.html и https://studia-mai.ru/personal-data-consent.html
- [ ] Владелец формы — ИП Болотова Г. И.
- [ ] На сайте блок `#booking` и модалка отзыва — **своя вёрстка** (iframe Яндекса пользователю не показывается). Заявка — POST `/api/yandex-form`. Отзыв — POST `/api/reviews/submit` (Яндекс + файл `data/published-reviews.json` на Node). На ленте сразу «Клиент», без поля ФИО; автор может **Удалить** свой отзыв (кнопка на карточке).
- [ ] **Админ:** в Timeweb задать `REVIEWS_ADMIN_KEY` (не короче 8 символов). Снять отзыв с сайта и получить `yandexAnswerKey` для удаления ответа в кабинете Яндекс.Форм: в консоли браузера на studia-mai.ru — `studiaMaiAdminDeleteReview('ID_отзыва', 'REVIEWS_ADMIN_KEY')`. Для сохранения отзывов между деплоями — `REVIEWS_FILE` на постоянный диск.
- [ ] **Timeweb: тип проекта Node.js**, путь `dist`, `npm start`. Если в ответах сервера `Server: Caddy` и POST `/api/yandex-form` даёт **405** — включён только статический хостинг, заявки не доходят (нужен Node или PHP с исполнением `api/yandex-form.php`).
