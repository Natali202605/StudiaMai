## 1. Резервное копирование

1. В панели Timeweb проверить, что резервное копирование сайта включено по тарифу/договору.
2. Записать в таблицу ниже: режим (ежедневно/еженедельно), срок хранения копий, ЦОД/регион из договора или панели.
3. Раз в квартал — контрольная проверка наличия свежей копии.

## 2. Ограничение доступа

- Доступ к ПДн: только лица из `docs/pd-access-list.md` (сейчас — Болотова Галина Ивановна).
- Пароли Timeweb, почты, Яндекс.Форм — уникальные; смена при передаче сайта и при увольнении/окончании работ подрядчика.
- Исходники API не раздавать с веб-корня (`/ops`, `/backend`, `/server` → 404).

## 3. Публикация отзывов

1. Принять ответ из Яндекс.Формы (текст + блок согласий + контакт + условия).
2. Проверить обе отметки согласия (обработка и распространение, версия документов).
3. Учесть условия/запреты автора.
4. На сайт выносить **только** ФИО (подпись) и текст; **контакт не публиковать**.
5. Записать id ответа Яндекса в журнал согласий.
6. Без согласия на распространение именно для https://studia-mai.ru/ — не публиковать (в т.ч. при переносе с другой площадки).

## 4. Удаление и сроки

| Категория | Срок | Действие по истечении |
|---|---|---|
| Заявки | 12 мес. | Удалить/обезличить в Яндекс.Формах и локальных выгрузках |
| Непубличные данные отзыва после снятия | 12 мес. после снятия | Удалить/обезличить |
| Сведения о согласиях | 3 года после окончания обработки | Уничтожить, если закон не требует иного |
| Обращения субъектов | 3 года с ответа | Уничтожить |

Обоснование сроков — в Политике (п. 7). Ежеквартальная сверка — обязанность ответственного.

## 5. Прекращение распространения

По `docs/subject-requests-and-breach.md` и п. 7.1 Политики: регистрация → проверка в сроки 152-ФЗ → снятие отзыва с сайта без публичной копии. Хранение без публикации — только на указанных законных основаниях.

## 6. Инциденты (утечки)

1. Немедленная фиксация и ограничение ущерба.
2. **В течение 24 часов** с выявления — первичное уведомление Роскомнадзора (в порядке 152-ФЗ и актов РКН).
3. **В течение 72 часов** — направление результатов внутреннего расследования (в установленном порядке).
4. При необходимости — уведомление субъектов.
5. Запись в журнале инцидентов; смена паролей/доступов.
