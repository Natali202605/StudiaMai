# Карта обработки персональных данных

Дата карты: 11 октября 2026 года. Это описание кода ветки `security/personal-data-intake`, а не подтверждение работающего сервера или законности обработки.

Разработчик сайта не назначается оператором. Реквизиты оператора, место базы и сроки хранения не подтверждены.

## Публичные страницы

| Что | Где в коде | Что происходит | Статус |
| --- | --- | --- | --- |
| Тексты, цены, фото, 49 опубликованных отзывов | `index.html`, `data/content.json`, `data/services.json`, `data/images.json` | Отдаются как файлы сайта | Подтверждено кодом. Основание публикации уже стоящих отзывов требует проверки оператором |
| Тема «Жемчуг» | `index.html` (`data-theme`), `data/theme.json` | Цвет страницы | Подтверждено кодом |
| Телефон студии, адрес, ссылки VK и mst.link | `index.html` | Показываются посетителю. Переход по ссылке — только после нажатия | Поставщик записи mst.link и схема его обработки не подтверждены |
| Шрифты | `style.css` | Используются семейства с запасными системными шрифтами. Автозапрос Google Fonts с главной, правовых страниц и админки снят | Подтверждено кодом |

## Заявка на звонок

| Поле | Цель | Куда уходит сейчас |
| --- | --- | --- |
| Телефон | Обратный звонок, если приём когда-либо включат | Никуда. `data/intake.json` содержит `enabled: false`. Форма не пишет `localStorage` и не вызывает FormSubmit, Web3Forms, Telegram и произвольный URL |
| Имя | Необязательное обращение | То же |
| Согласие | Отдельная отметка | Без отметки `true` серверная проверка `validateCallbackRequest` отклоняет запись. Сейчас серверный приём тоже выключен |
| Фамилия, email, комментарий | Не собираются в базовой форме | Поля убраны из `index.html` |

Обработчик на GitHub Pages: собственного API нет (`js/config.js` для этого адреса оставляет API пустым). Файл `server/server.js` в репозитории не означает, что он запущен.

## Отзывы

Уже размещённые 49 текстов остаются на странице. Новая кнопка отзыва не добавляет карточку в слайдер и не сохраняет автора в браузере. `POST /api/reviews` отвечает отказом. Имена уже опубликованных отзывов в этот файл не копируются.

## Админка

Проверка пароля в браузере не является серверной защитой. Пароль больше не записывается в `localStorage`. Стандартный пароль из клиента не принимается. Список заявок из публичного `data/bookings.json` не используется как хранилище новых данных: приём выключен.

## Внешнее хранилище настроек

Публичный `js/live-store.js` больше не содержит токен записи и не обращается к внешнему хранилищу при открытии страницы. Публичный контент берётся из файлов `data/*.json`.

## Что требует сведений оператора

Страна и адрес базы, провайдер, срок хранения, полное имя и контакты оператора, основание для уже опубликованных отзывов, поставщик онлайн-записи. См. `docs/operator-required-input.md`.
