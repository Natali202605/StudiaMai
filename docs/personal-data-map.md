# Карта данных

Это описание по коду на 15 октября 2026 года. Оно не подтверждает договор с хостингом и не заменяет сведения оператора.

## Заявка с сайта

- Поля формы не менялись: имя, фамилия, телефон, email, комментарий, отдельное согласие.
- Цель: обратный звонок и запись в студию. Юридическое основание оператор ещё не утвердил.
- На опубликованном сайте GitHub Pages собственного API нет. Заявка уходит письмом на почту студии через FormSubmit и копируется в список админки этого браузера (`localStorage`).
- Получатель письма: почтовый адрес студии, уже указанный на сайте. FormSubmit — внешний сервис, страна обработки в проект не передана.
- Web3Forms, Telegram и произвольный URL заявок из браузера отключены.
- Если позже подключён собственный API, `server/server.js` принимает те же поля только при `consent === true`, ограничивает длину и частоту и не отдаёт текст заявки в ответе.

## Админка

- На GitHub Pages вход в админку проверяется в браузере. Это не серверная защита.
- На собственном сервере список заявок, правки и новые отзывы требуют авторизации. Открытая регистрация администратора выключена. Смена пароля отзывает прежнюю сессию.

## Публичный контент

- Тексты, цены, фото и палитра по-прежнему правятся из админки. В публичные настройки попадает только адрес почты для уведомлений, без токенов.

## Что не хранится как доказательство

- IP и User-Agent в заявку не записываются.
- Срок хранения оператор не задал.
