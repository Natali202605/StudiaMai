# Факты для уведомления оператора

Каждое утверждение помечено. Уведомление по статье 22 подаёт фактический оператор. Этот файл уведомлением не является и никуда не отправляется.

| Сведение | Состояние |
| --- | --- |
| Оператор | Нужны сведения оператора |
| Цели | В коде подготовлена только цель обратного звонка. Другие цели обработки вне сайта не подтверждены |
| Набор данных заявки | Телефон и необязательное имя. Фамилия, email и комментарий в базовой форме не запрашиваются |
| Категории субъектов | Посетители сайта, которые когда-либо отправят заявку. Сейчас приём выключен |
| Основание | Не выбрано оператором. Черновик рассчитан на отдельное согласие, но текст не утверждён |
| Операции | Сбор через форму подготовлен, но выключен. Хранение, уточнение и удаление на рабочей базе не запущены |
| Способы | Публичные страницы — статические файлы. Собственный API в рабочей среде не подтверждён |
| Меры | Описаны в `docs/security-audit.md` как изменения кода, не как аттестованная защита |
| Криптосредства | Использование конкретных средств не подтверждено. Название не указывается |
| Дата первого сбора | Неизвестна. Дата этой доработки не подставляется вместо неё |
| Прекращение | Срок не задан оператором, поэтому рабочий приём не включён |
| Ответственное лицо | Нужны сведения оператора |
| Базы и адреса | Нужны сведения оператора и провайдера. Адрес студии на странице не является адресом базы |
| Трансграничная передача | Автоматическая отправка заявок за рубеж из браузера отключена. Размещение самого сайта и переход по внешним ссылкам записи требуют отдельной проверки статьи 12. Запись в обычном уведомлении эту процедуру не заменяет |
| Уже поданное уведомление | Нужны дата, номер, содержание и срок ответа, если письмо Роскомнадзора уже есть. Они здесь не изобретаются |

Исключения старых памяток про «только сотрудников», «только договор» и «только ФИО» как основание не уведомлять не используются.
